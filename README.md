# 🩸 Blood Bank Management System

A web-based blood bank management system built using **Python, Flask, and MySQL** to help manage blood donors, monitor blood stock, and handle blood requests efficiently.

## 📌 About the Project

Managing blood donations and blood availability manually can be difficult, especially when blood is urgently needed. This project provides a centralised system to organise donor information, track available blood stock, and manage requests through a web interface.

## ✨ Key Features

- **Donor Management** — Store and manage blood donor information.
- **Blood Stock Tracking** — Maintain records of available blood units.
- **Blood Request Handling** — Manage requests for required blood groups.
- **Web Interface** — Access the system through a browser.
- **Database Integration** — Use MySQL to store and manage application data.
- **Health API Integration** — Includes real-time health API integration as described in the project overview.

## ⚙️ Getting Started

### Prerequisites

- Python installed
- MySQL installed and running
- Git installed

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/avaniverma612-pixel/bloodbank.git
   cd bloodbank
   ```

2. Install the required Python packages, if a dependency file is available:

   ```bash
   pip install flask mysql-connector-python
   ```

3. Configure your MySQL database and connection settings according to your local setup.

4. Start the application:

   ```bash
   python app.py
   ```

5. Open the local address displayed in your terminal, usually `http://127.0.0.1:5000`.

*Note: Database configuration and additional dependencies may need to be adjusted for your environment.*
